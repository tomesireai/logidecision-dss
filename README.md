# LogiDecision

Учебная система поддержки принятия решений для оптимизации логистической цепочки.

## Возможности

- поиск оптимального маршрута по алгоритму Дейкстры;
- выбор перевозчика методом TOPSIS;
- планирование сроков методом PERT;
- сравнение сценариев и оценка рисков.

## Запуск

Скачайте файлы проекта и откройте `index.html` в браузере. Установка дополнительных программ не требуется.
